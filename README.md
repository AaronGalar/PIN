# PIN - Patrimonio Inmaterial Navarra / Nafarroako Ondare Materiagabea

Proyecto Final para el Módulo de HTML y CSS. Una plataforma intuitiva, accesible y educativa dedicada a la historia, tradiciones y festividades de la Comunidad Foral de Navarra.

## 📝 Descripción
Este sitio web funciona como un laboratorio de experimentación donde se combina la divulgación histórica con competencias digitales avanzadas. Permite explorar el patrimonio cultural inmaterial de Navarra, consultar eventos mediante datos abiertos y registrar nuevos bienes culturales.

## 📂 Estructura del Proyecto
El proyecto está organizado de forma semántica y modular:
* **/htmls:** Páginas individuales de cada sección (Historia, Eventos, Galería, etc.).
* **/imagenes:** Recursos visuales y galería fotográfica.
* **/scripts:** Lógica de interacción, validación de formularios y sistema multilingüe.
* **/styles:** Hojas de estilo CSS (Global y específicas) con animaciones.
* **index.html:** Eje central de navegación.

## 🛠️ Tecnologías y Técnicas Aplicadas
* **HTML5 Semántico:** Uso de etiquetas como `<header>`, `<main>`, `<section>` y `<footer>`.
* **CSS3 Avanzado:** * Maquetación con **Flexbox** (Eventos) y **Grid** (Galería).
    * Animaciones personalizadas con `@keyframes` y transiciones suaves.
    * Diseño **Responsive** adaptable a dispositivos móviles.
* **JavaScript (DOM):** * Sistema de cambio de idioma (Español/Euskera).
    * Uso de **LocalStorage** para el pop-up de bienvenida.
    * Validación de formularios con `preventDefault()`.
* **Integración de Datos (APIs):**
    * Consumo de datos de **Open Data Navarra** mediante `Fetch` y `JSON` para la sección de Eventos.
    * Integración de mapas interactivos mediante iframes.

## 🏛️ Secciones Principales
1.  **Historia:** Definición del patrimonio inmaterial con mapa interactivo y Biblioteca Abierta.
2.  **Eventos:** Buscador interactivo conectado a APIs de datos abiertos.
3.  **Galería:** Muestra visual responsive del patrimonio navarro.
4.  **Registro:** Formulario interactivo para la contribución de nuevos bienes culturales.
5.  **Login:** Simulación de acceso restringido para administración.

## 🚀 Experimentación y Futuro
Este proyecto se plantea como un punto de partida para:
* Creación de APIs propias sobre cultura e historia ante la falta de recursos actuales.
* Implementación de traducción automática avanzada (basada en experimentos previos con Itzuli API).
* Mejora visual profesional manteniendo la identidad corporativa de Navarra (Rojo Navarra).
